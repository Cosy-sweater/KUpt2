# KU p2

## Описание проекта
Данный проект является учебным заданием курса "конфигурационного управления",
в рамках которогосразрабатывается CLI приложение, визуализирующие граф
зависимостей для менеджера пакетов.

## Запуск и использование приложения
При запуске программы, задаются аргументы:
- Имя анализируемого пакета package.
- URL-адрес репозитория или путь к файлу тестового репозитория path.
- Режим работы с тестовым репозиторием test_mode.
- Режим вывода зависимостей в формате ASCII-дерева tree_mode.
- Подстрока для фильтрации пакетов filter.

Присутствует валидация аргумента path.

## Функции проекта
На данном этапе программа проверяет наличие необходимых аргументов,
и в случае их правильности, выводит список аргументов в консоль
